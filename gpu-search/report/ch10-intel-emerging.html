第十一章：Intel Gaudi与新兴AI芯片架构

在NVIDIA与AMD的GPU双雄对决之外，一批采用全新架构哲学的AI芯片正在挑战传统范式。Intel Gaudi以标准以太网替代专有互联，Groq LPU以确定性张量流架构重新定义推理延迟，Cerebras WSE-3以整片晶圆为芯片突破光罩极限，Tenstorrent则以RISC-V核心构建可扩展AI计算网格。这些"非主流"方案虽市场份额微小，但其架构创新正在为AI计算的未来开辟全新赛道。

12.1 Intel Gaudi：以太网原生的AI加速器

2019年，Intel以20亿美元收购以色列AI芯片初创公司Habana Labs，获得了Gaudi架构。Gaudi最激进的设计理念是：用标准以太网（RoCEv2）替代所有专有互联协议，在芯片内部直接集成24个200GbE网络端口。

以太网互联的战略逻辑

Gaudi最核心的架构选择——片上24端口RoCEv2引擎——意图从根本上瓦解NVIDIA NVLink+InfiniBand的专有互联优势。其逻辑是：以太网是全球最成熟、成本最低的网络技术，每代带宽翻倍（100G→200G→400G→800G），不需要专用交换机（NVSwitch 售价 $20K+）。Gaudi 3的24×200GbE端口理论上可构建全互联拓扑（每卡至少4.8 Tb/s聚合带宽），足以支撑中等规模的训练集群。

然而，现实挑战同样严峻：RoCEv2在处理大规模All-Reduce集合通信时，延迟（~3-5μs）仍高于NVLink+Sharp协议（~1μs），且以太网的拥塞控制和丢包恢复机制在大规模GPU集群中可能导致训练吞吐不稳定。Intel的应对策略是硬件加速集合通信引擎（在Gaudi芯片内直接卸载All-Reduce操作），将软件协议栈开销降至最低。

Intel Falcon Shores：原计划2025年发布的Falcon Shores被寄予厚望——将Intel Xe GPU架构与Gaudi AI引擎融合为一款"XPU"。但该项目在2024年经历了重大调整：GPU部分被取消，改为纯Gaudi路线的延续。这深刻反映了Intel在AI芯片方向上的战略纠结。

12.2 Groq LPU：确定性张量流架构

Groq Language Processing Unit (LPU)

Groq（不是Elon Musk的Grok）由前Google TPU团队核心成员Jonathan Ross创立，其LPU架构的最根本特征是完全放弃HBM，全部计算数据驻留在片上230MB SRAM中，以软件调度的确定性数据流替代传统GPU的缓存-预取-猜测执行范式。

  • 架构哲学：编译器在编译时确定每个张量操作的精确时序（Cycle-accurate），所有数据的流入流出都在编译器生成的控制流中确定化——不依赖运行时分支预测或动态调度→实现极低且确定的延迟
  • 性能特征：Llama-2 70B推理速度>300 tokens/s（单LPU），延迟<10ms，远超GPU的50-100 tokens/s
  • 内存策略：230MB片上SRAM → 模型必须通过"软件定义内存"进行细粒度分片和流水化→独创的模型分片方式与GPU截然不同
  • 潜在短板：完全放弃HBM使得超大模型（>400B参数）训练极不现实；230MB SRAM容量上限决定了LPU在训练市场的天花板

12.3 Cerebras WSE-3：晶圆级计算的极致形态

Cerebras Wafer-Scale Engine 3 (WSE-3)

如果芯片设计的最终极限是"尽可能大"，Cerebras将这一理念推到了极致：WSE-3是一整片晶圆，面积46,225mm²——约为NVIDIA H100显卡核心面积的57倍。它包含4万亿晶体管、900,000个AI优化核心和44GB片上SRAM。

  • 物理极限突破：传统芯片受光罩（Reticle）面积限制（~858mm²），Cerebras通过冗余路由和缺陷容错技术，在整片300mm晶圆上直接蚀刻一个完整的计算系统
  • 内存架构：44GB全片上SRAM，带宽高达21 PB/s——不需要HBM，不需要外部DRAM
  • 独特优势：单晶圆即可完成GPT-3级别模型的完整训练（无需集群），延迟极低
  • 关键局限：单台WSE-3系统售价百万美元级，专为超大客户定制；功耗20kW+，需要专用液冷系统
  • 客户生态：G42（阿联酋）、美国阿贡国家实验室等超大规模客户

12.4 Tenstorrent：RISC-V驱动的可扩展网格

Tenstorrent Blackhole & Grendel

由传奇CPU架构师Jim Keller（曾领导AMD Zen、Apple A4/A5、Tesla Autopilot芯片设计）创立的Tenstorrent，选择了一条完全不同的技术路径：以RISC-V处理器核心为基本单元，通过2D Mesh网络构建可无限扩展的AI计算网格。

  • Blackhole (2024)：140个Tensix核心（每个含5个RISC-V小核+矩阵引擎），128MB SRAM，PCIe Gen5
  • Tensix核心：每个核心包含计算引擎+网络路由器，形成自路由的2D网格→核心数量可线性扩展（无共享总线瓶颈）
  • RISC-V策略：全部控制逻辑使用开源RISC-V ISA，完全规避ARM/x86授权费和出口管制风险→在制裁环境下具有独特合规优势
  • 软件栈：TT-Metalium（底层） + TT-BUDA（编译器）+ PyTorch前端→编译流程偏复杂

12.5 Graphcore IPU与SambaNova

Graphcore IPU (Intelligence Processing Unit)

英国Graphcore的IPU采用MIMD（多指令多数据）架构，每个IPU包含1,472个独立处理核心，各自拥有本地SRAM和独立程序计数器。这种设计允许每个核心执行不同的指令序列，相对于GPU的SIMT模型，在稀疏计算和动态控制流场景中具有天然效率优势。C600 IPU在特定图神经网络推理场景中可达到H100的3-5倍吞吐。但Graphcore在2024年面临严重财务困境，已被软银收购。

SambaNova SN40L：可重配置数据流架构

SambaNova的核心理念是"软件定义硬件"：其RDU（Reconfigurable Dataflow Unit）允许编译器根据模型拓扑动态重配置计算单元间的数据通路——类似于FPGA的逻辑重配置，但粒度更粗、频率更高。SN40L拥有1,040个可重配置计算单元和520MB SRAM，在Transformer类模型中可实现极高的计算单元利用率（>80% vs GPU的30-50%）。
